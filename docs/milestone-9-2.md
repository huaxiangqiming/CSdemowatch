# M9.2 配色与签名发布准备

版本：0.9.2-beta.1 未签名预发布。日期：2026-10-01。

## 配色

背景与地图改为协调的 Stone、Mist、Slate 三组颜色；默认降低背景亮度、提高地图亮度，减少近黑模型贴浅背景的强烈反差。面板从纯白改为柔和灰白。Settings → Map & Background 同时控制地图、背景和备用平面，沿用旧设置键，不使既有配置失效。

颜色集中在 ScenePalette.gd。普通材质、透明材质和剖切材质使用同一个地图色，地图热重载后仍保留选项。没有改变地图网格、屋顶分类、导航支撑、玩家队伍色、坐标或回放事实。

## 签名

安装器和三个应用 EXE 已接入证书库签名流程；Inno 同时配置卸载器签名。正式打包默认要求证书，通过显式 AllowUnsignedPreview 才能生成独立目录中的未签名 UI 预览。证书、签名、时间戳或校验失败即中止。

本机没有可用代码签名证书，项目所有者的签名身份与所在地区仍待确认，因此**发布者验证问题尚未完全解决**。没有创建自签证书或关闭 Windows 保护，签名尚未完成；后续按用户明确推送授权公开分发同一未签名预览，文件名与说明均保留未签名标识。签名方式和后续前提见 [Windows 签名说明](windows-signing.md)。

## 验证

16 项界面/设置检查通过；52 项 Ancient、Mirage 配色检查通过，涵盖三套色板、透明度、剖切、重载与备用平面，玩家状态保持一致。两张地图截图已检查。

PowerShell 脚本语法验证通过；正式打包缺少证书时明确失败，且失败发生在重建或替换发布产物之前。没有证书条件下无法完成真实签名端到端验收，不将失败路径检查当作签名成功。

证据位于 `artifacts/m92/`。本地 UI 预览包与签名状态在 `dist/previews/0.9.2-beta.1/`。

## 回合导航与 ±15 秒

按用户调整后的优先级，签名身份申请暂缓，先完成软件内配色和播放操作。时间轴新增“上一回合”“下一回合”和“±15 秒”三个控制区（±15 秒各一个按钮），所有操作只调用 ReplayClock.seek。倍速和播放/暂停状态保留，抵达末尾自动暂停；拖动时间轴或读取失败时禁用快捷跳转。

RoundNavigation 从现有 V2 的 bomb_reset 事件建立索引，该事件在 Parser 中仅由实际 RoundStart 回调生成，并非通过炸弹结果推算。旧二进制和 JSON 缓存直接适用，不更改事实格式。相同时间的重复起点合并；首个已记录起点之前不补造回合；导航序号是记录顺序，可能包含重开，不等于比赛比分。V1 或缺少起点的回放仍支持 ±15 秒，回合按钮禁用并显示原因。

Ancient 有 21 个记录起点、Mirage 有 10 个；独立 TestBombPublicDemo 对 Ancient 源 Demo 回调核对，全部相关 tick 一致。播放导航验收覆盖边界、重复起点、忽略其他 Bomb 事件、播放状态及倍速、拖动、读取错误、旧回放、真实跨块跳转和 960/1280 窗口。截图显示中文按钮可读且没有溢出。

最终安装包验收：实际安装 EXE 的播放导航 50 项、安装流程 13 项以及真实 Demo/缓存 11 项均通过；基础回放 84 项通过。新增错误发生于拖动时不会自动恢复播放的保护。最终证据为 `navigation-installed-report.json`、`navigation-installer.log`、`navigation-installer-check/`，预览包已包含新的导航按钮。签名身份工作根据用户最新要求暂缓，随后按用户“推送到 github”授权，发布相同验收产物与中英文说明；没有替换旧版本安装包，也没有宣称发布者验证通过。
