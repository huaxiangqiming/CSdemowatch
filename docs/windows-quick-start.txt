Windows 安装与启动 / Install and launch

从 GitHub Releases 下载 *-setup.exe 并运行，或下载 *-portable.zip 后完整解压。
安装版提供中英文向导，无需安装 Go/Godot；默认仅安装到当前用户，不要求管理员权限。
这是未签名的 Beta 版本，Windows 可能显示发布者未验证提示；请核对发布页 SHA256SUMS.txt。
卸载移除应用，保留 %LOCALAPPDATA%/CS2TacticalReplay 中的个人设置和缓存。
地图准备需要本机合法安装的 CS2；安装包不包含 Valve 地图。

Download *-setup.exe from GitHub Releases, or extract the entire *-portable.zip.
The installer supports English / Simplified Chinese and installs for the current user.
This beta is unsigned; Windows may show an unverified publisher prompt.
Verify SHA256SUMS.txt from the release. Uninstall preserves user settings and caches.

CS2 Tactical Replay — v0.9.2-beta.1

1. Keep this entire folder: EXE, PCK, cs2parser.exe, cs2maptool.exe and map-tools
   (Source2Viewer CLI, its DLLs and MIT license).
2. Double-click CS2TacticalReplay.exe. No Godot, Go, Python or VRF install is needed.
3. Choose Open Demo or drop one .dem file into Home. Processing stays local.
4. Missing/stale maps use Debug Plane immediately after Replay loading.
   New settings default to Auto: discover CS2, prepare the map in the background,
   then load it automatically. Old Ask/Never preferences are preserved.
5. Use Play/Pause, Timeline and 0.5x/1x/2x. Wheel zooms; right-drag pans.
   Map hot swap preserves time, speed, camera, selection and layers.
   View > Height cutaway defaults on for real replays. It hides geometry above
   the highest living-player track plus headroom. Lower the slider to inspect
   lower floors, or turn it off to restore the complete prepared map.
   Cutaway affects map rendering only; players and combat effects are unchanged.
6. Settings > MAPS: browse CS2, select Auto/Ask/Never, Prepare, Rebuild,
   Delete Cache or View Log. Ask uses Prepare then Load Map in the View tab.
   Each app instance prepares at most one map at a time.
7. No CS2 or failed conversion never blocks a successfully parsed Replay.
   Set the installation path and Retry/Prepare without reparsing the Demo.
8. Home returns to Recent Replays, showing Map Ready or Map Missing.
9. View > Debug / Player Status shows source/cache/preparation, geometry and
   player diagnostics. Normal playback UI hides developer paths.

Cache/settings/recent/logs: %LOCALAPPDATA%/CS2TacticalReplay/
Maps and Replay caches are independent; another Demo on the same map reuses it.
Source file and converter/classifier version changes invalidate generic maps.
The package contains no Valve mesh. Preparation reads local CS2 resources only.

Verified preparation/playback: Ancient, Mirage, Dust2, Vertigo, Inferno.
Inferno alignment uses two short real public clips, not a full match.
Nuke is unverified. Other maps may prepare automatically or use Plane.
Geometry is gray collision data, without original materials or lighting.
Conservative roof classification protects walkable floors and keeps unknown faces.
Some small/sloped roofs and upper floors still obscure lower areas; transparency
can help. Inferno has 2.67M triangles and exceeds the target complexity budget.
Large JSON Replays take seconds to load. Cancel waits for the current tool.
No account or cloud service is required. Advanced tactical analysis is not included.

Full scope, measurements, screenshots and known issues: docs/milestone-9-1.md
in the source project.

New Demo caches use indexed .replay files. Older JSON caches remain readable.
Player tracks load on demand; events and projectiles currently remain resident.

Appearance: Settings > Map & Background selects coordinated Stone, Mist or Slate palettes.
The Panels button hides the side tools for an unobstructed map view.

Playback navigation: 上一回合 / 下一回合 jump to recorded round starts.
−15 秒 / +15 秒 skip exactly 15 replay seconds and clamp at the ends.
Playback speed and paused/playing state are preserved, except reaching the end pauses.
Round numbers count recorded starts, including restarts; they are not the match score.
Replays without recorded starts keep the 15-second controls; round buttons are disabled.
