## 中文

地图默认显示大小增加约 40%，姓名直接显示在玩家上方，不使用姓名底牌或连接线。打开回放时默认收起右侧面板，通过 Panels 可重新展开；滚轮继续缩放，Home 恢复默认视角。

- 修复 Demo 文件选择器深色底配深色字的问题，统一浅色窗口、列表、文字及选中态。
- 文件选择器默认使用列表视图，从最近的有效 Demo 目录开始；没有历史时使用文档目录。
- 小窗口保留字号，播放操作和时间/倍速控件自动换行。
- 地图采用中性光照，增强地图、背景与玩家的区分。
- 死亡玩家姓名默认隐藏，可在图层或设置中重新开启。
- 保留上一/下一回合、±15 秒、旧回放兼容和本地缓存。

**下载**：Windows x64 安装版选择 `setup-unsigned-preview.exe`；免安装版选择 `portable-unsigned-preview.zip` 并完整解压。

**签名状态**：本版本尚未签名，发布者验证问题仍未解决。安装包不含真实 Demo 或 Valve 地图资源。校验值见 `SHA256SUMS.txt`。

**验证**：Ancient 和 Mirage 在 960×640、1280×800、1440×900 下的 53 项显示/镜头检查均通过，打包后的 EXE 再次通过；84 项回放核心、界面输入和镜头检查通过。

## English

The default map view is about 40% larger. Names remain directly above players, with no nameplates or connector lines. The side panel starts collapsed and can be reopened with Panels. Use the wheel to zoom and Home to restore the default view.

- Fixed dark text on dark surfaces in the Demo file picker with a consistent light theme.
- Default list view starts in the most recent valid Demo directory, or Documents when no history exists.
- Smaller windows retain readable text sizes; playback and time/speed controls wrap as needed.
- Neutral map lighting improves separation between the map, background and players.
- Dead-player names are hidden by default and can be restored in layers or settings.
- Previous/next round, ±15-second controls, legacy replay support and local caching remain available.

**Download**: choose `setup-unsigned-preview.exe` for the Windows x64 installer, or fully extract `portable-unsigned-preview.zip` for portable use.

**Signing**: this build is unsigned; publisher verification is still unresolved. No real demos or Valve map assets are bundled. Verify downloads against `SHA256SUMS.txt`.

**Validation**: 53 display/camera checks passed with real Ancient and Mirage replays at three window sizes, including the exported EXE. All 84 core replay, UI input and camera checks passed.
