# v0.9.2-beta.1 — 柔和地图配色与回合跳转 / Softer maps & round navigation

## 中文

本次是**未签名预发布版本**，发布者身份验证尚未完成，Windows 仍可能显示未验证发布者或 SmartScreen 提示。安装包名称中的 `unsigned-preview` 为明确标记；签名工作按当前开发优先级暂缓。

- 地图与背景改为协调的 **Stone / Mist / Slate** 三套配色，默认降低背景亮度并提亮地图，面板改为柔和灰白，减少强烈明暗反差。
- **Settings → Map & Background** 同时切换背景、地图材质和备用平面；透明度、屋顶剖切和地图重载保持兼容。
- 时间轴新增 **上一回合、下一回合、−15 秒、+15 秒**。保持倍速与播放/暂停状态，到末尾自动暂停；拖动或读取失败时禁用快捷跳转。
- 回合起点来自 Demo 实际记录，现有 V2 JSON / 二进制缓存可直接使用。序号按记录顺序计数，可能包含重开，不代表比分。没有起点记录的回放仍可使用 ±15 秒。
- 开发工具已加入签名与时间戳校验，正式打包默认要求证书；本包通过显式未签名预览模式生成，不代表签名问题已经解决。

**下载：** 选择 `*-setup-unsigned-preview.exe` 安装；或完整解压 `*-portable-unsigned-preview.zip` 后启动 `CS2TacticalReplay.exe`。中英文安装向导，当前用户安装，卸载保留独立设置和缓存。文件校验值见 `SHA256SUMS.txt`。

**环境与限制：** Windows 10/11 x64、OpenGL 3.3。无需另装 Godot / Go / Python。地图准备需要本机合法安装的 CS2；包内不含 Valve 地图或真实 Demo。事件与投掷物仍整体加载，密集姓名可能重叠，部分地图及 Demo 版本仍属实验支持。

**验收：** 52 项地图配色、16 项界面/设置、84 项基础回放检查通过；实际安装 EXE 的 50 项导航检查、13 项安装流程检查和 11 项真实 Demo/缓存检查通过。Ancient 的 21 个回合起点已与原始 Demo 独立核对。验证基于本机 Windows 环境，不等于全部机器兼容性承诺。

## English

This is an **unsigned prerelease**. Publisher identity verification is not complete, and Windows may still show an unverified publisher or SmartScreen warning. The `unsigned-preview` filenames explicitly identify this status; signing has been deferred under the current development priorities.

- Coordinated **Stone / Mist / Slate** map/background palettes, softer off-white panels, a dimmer default background and brighter map geometry reduce harsh contrast.
- **Settings → Map & Background** changes the scene, map materials and fallback plane together, including transparency, height cutaways and map reloads.
- New **previous round, next round, −15 seconds and +15 seconds** controls. Playback speed and playing/paused state are preserved, except reaching the end pauses. Seeking controls are disabled during scrubbing or read errors.
- Navigation uses recorded round starts and works with existing V2 JSON/binary caches. Indices count observed starts, including restarts, rather than match scores. Replays without starts retain ±15-second seeking.
- Signing and timestamp verification are wired into production packaging, which now requires a certificate. This release was explicitly built as an unsigned preview and does not claim verified publisher status.

**Download:** run `*-setup-unsigned-preview.exe`, or extract the entire `*-portable-unsigned-preview.zip` and launch `CS2TacticalReplay.exe`. The English/Chinese installer is per user and uninstall preserves separate settings/caches. Verify downloads with `SHA256SUMS.txt`.

**Requirements and limits:** Windows 10/11 x64 and OpenGL 3.3. No separate Godot, Go or Python installation is needed. Map preparation requires a legitimate local CS2 installation; no Valve maps or real demos are bundled. Events/projectiles still load eagerly, dense player labels may overlap and some maps/demo versions remain experimental.

**Validation:** 52 palette, 16 UI/settings and 84 basic replay checks passed. The installed EXE passed 50 navigation checks, alongside 13 installation and 11 real-demo/cache checks. Ancient's 21 round markers were independently verified against source events. Results reflect the local Windows test environment.
