# 0.9.1-beta.1 — 浅色界面与 Windows 安装版 / Light UI & Windows installer

## 中文

下载 **CS2TacticalReplay-0.9.1-beta.1-windows-x64-setup.exe**，双击选择中文或英文并完成安装，然后从开始菜单打开。安装程序默认安装到当前用户目录，不要求管理员权限。也可下载 **portable.zip**，完整解压后运行 `CS2TacticalReplay.exe`。

- 默认浅蓝灰背景、白色面板与深色文字；设置中可选择浅蓝灰、柔灰、深灰背景，自动保存。
- 统一首页、设置、时间轴和侧栏样式；侧栏随窗口高度调整，Panels 按钮可收起工具面板。
- 回放中可以直接打开另一份 Demo；外观设置前置，观察控制默认可见。
- 集成本地 .dem 解析、M9 二进制缓存、10 秒轨迹窗口及相邻窗口后台预取；旧 JSON 缓存继续兼容。
- 安装包包含 Godot 运行时、Parser、地图工具及第三方声明，无需单独安装 Go、Godot 或 Python。
- 提供安装版、免安装版和 `SHA256SUMS.txt`。卸载保留个人设置及独立回放/地图缓存。

**运行环境与限制：** Windows 10/11 x64，支持 OpenGL 3.3 的显卡。当前是未签名 Beta，Windows 可能提示发布者未验证；请核对 SHA-256。地图准备需要本机合法安装 CS2，包内不含 Valve 地图或真实 Demo。没有 CS2 时仍可在备用平面上查看成功解析的回放。应用界面目前为英文，安装向导和此说明支持中英文。

事件/投掷物目前仍整体加载；密集玩家姓名可能重叠；部分地图与历史 Demo 版本仍属实验支持。这次发布不是完整 M10–M14 功能完成声明。

验收：16 项界面/设置检查、84 项基础回放检查、Go 全套测试、12 项安装流程检查，以及从实际安装 EXE 执行的 11 项真实 Demo/缓存检查通过。安装路径覆盖空格和中文，安装、重复安装、卸载保留数据已验证。本机测试不等于所有 Windows 环境均已覆盖。

## English

Download **CS2TacticalReplay-0.9.1-beta.1-windows-x64-setup.exe**, run the English or Simplified Chinese installer, then launch the application from the Start menu. Installation is per user and does not request administrator privileges. Alternatively, extract the complete **portable.zip** and run `CS2TacticalReplay.exe`.

- Light blue-gray scene, white panels and dark text. Choose and save light blue-gray, soft gray or dark slate backgrounds in Settings.
- Consistent Home, Settings, timeline and tool panels; responsive sidebar height and a Panels button for a larger map view.
- Open another demo directly from playback; appearance settings appear first and viewing controls are selected by default.
- Includes local demo parsing, compressed replay caches, bounded ten-second track windows and background read-ahead. Existing JSON caches remain supported.
- Bundles the runtime, parser, map preparation tools and third-party notices; no separate Godot, Go or Python installation is needed.
- Installer, portable ZIP and SHA-256 checksums. Uninstall preserves separate user settings and replay/map caches.

**Requirements and limits:** Windows 10/11 x64 and OpenGL 3.3 graphics. This beta is unsigned and Windows may display an unverified publisher warning; verify the published checksums. Preparing tactical maps requires a legitimate local CS2 installation. No Valve maps or real demos are bundled. Without CS2, successfully parsed demos remain usable on the fallback plane. The application UI is currently English; the installer and release notes support both languages.

Events and projectiles still load eagerly, dense player labels may overlap, and some maps/demo versions remain experimental. Advanced analysis and the complete product roadmap are not finished.

Validation: 16 UI/settings checks, 84 basic replay checks, the Go test suite, 12 installation checks and 11 real-demo/cache checks from the installed EXE passed. Installation, reinstall and uninstall were exercised in a path containing spaces and Chinese characters. Validation reflects the local test machine, not every Windows configuration.
